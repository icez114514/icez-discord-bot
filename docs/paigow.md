# 牌九撲克：全萬用 Joker（#11、#12）

## 玩法

/賭場 → 牌九撲克 → 基本下注與倍率 → 開局。
玩家與莊家從同一副 53 張牌各取得七張，牌面编号對應選單中的 1–7。
選兩張前墩，其餘五張自動成為後墩；預覽後按「確認分牌」揭曉莊家。
「自動分牌」只填入建議，可在確認前自行修改。倒墩或無效選牌只提示修正，不扣輸。

Joker 是一張全萬用實體牌，僅在所在墩取最強代表牌；替代的點數／花色允許與自然牌重複。
因此 Joker＋K 為 KK，四張 7＋Joker 為五條 7。五條最高，其後依序為同花順、四條、
葫蘆、同花、順子、三條、兩對、對子、高牌。前墩只有對子與高牌。
同花順與順子均以 AKQJ10 最大、A2345 第二，其後 KQJ109 至 23456。
天然牌與萬用牌同等評分時不另分高低；花色也不分大小。

後墩必須強於前墩：先比牌型，再比共同長度中的點數及踢腳。
共同部分相同時，五張後墩的剩餘踢腳使其較強。Joker 不能故意降級來規避倒墩。

同墩平手算莊家勝：玩家勝兩墩為勝、勝一墩為和、零勝為負。
免抽水，下注 100 的勝／和／負返還為 200／100／0（淨額 +100／0／−100）。
沒有邊注、加注或玩家坐莊。

## 固定 House Way：wild-house-v1

分墩只讀取該方七張牌，不根據另一方手牌選擇；自動分牌不是保證獲勝或最優策略。
先列舉 21 種前墩選法，排除倒墩。每個候選墩的 Joker 均獨立取最強牌型。
Joker 有多個同分代表牌時，以最小代表牌 ID 決定顯示（黑桃、紅心、方塊、梅花；各花色 A 至 K）。

下表為判定順序。分組統計時 Joker 暫計入自然牌數量最多的點數，同數量選較大點數；
這只是用來選決策列，實際各墩 Joker 評分仍完全萬用。
每列符合的分墩中先選前墩最強，再選後墩最強，同分選排序後前墩實體牌 ID 最小者。
若該列沒有合法候選，使用後墩最強、再前墩最強、最後前墩 ID 最小的固定保底。

| 七張牌分類 | 分墩偏好 |
| --- | --- |
| 五條＋另外一對 | 保留後墩五條，另外一對放前墩 |
| 五條、沒有另外一對 | 五條的對子放前墩，後墩至少三條 |
| 四條＋另外一對／三條 | 保留四條，另外一對放前墩 |
| 四條 2–6 | 保留後墩四條 |
| 四條 7–10 | 有 A 高牌可放前墩則保留四條，否則拆成兩墩對子 |
| 四條 J–A | 拆成兩墩對子 |
| 三條＋對子／兩對／另一组三條 | 最強可用對子放前墩，後墩為三條或葫蘆 |
| 三對 | 最大對子放前墩 |
| 兩對，兩對都是 J 以上，或較小對子為 7–10 且較大對子為 J 以上 | 拆對，較小對子放前墩 |
| 其他兩對 | 若前墩可放 A 高牌則保留後墩兩對，否則拆對 |
| 剩餘分類有順子／同花／同花順 | 保留後墩上述任一牌型，優先前墩最強；可以放前墩對子時自然優先 |
| 三條 A、且未使用前列 | 前墩 A 高牌，後墩 AA |
| 其他三條、且未使用前列 | 保留後墩三條 |
| 一對、且未使用前列 | 保留後墩對子，最大的兩張散牌放前墩 |
| 高牌、且未使用前列 | 第二、第三大的牌放前墩 |

例如 2♠、4♥、6♦、8♣、10♠、K♥、Joker 會進入一對列，選 K♥＋10♠ 為前墩，
Joker 在後墩與 8♣ 組成對子。分組時暫計的 KK 不限制候選 Joker 的實際點數；
依此列「先前墩最強」的固定排序選擇，並非固定保留 KK。

參考起點為 [MotorCity House Way](https://www.motorcitycasino.com/tablegames.aspx?page=paigow)。
本 bot 的 Joker 全萬用、任意點數五條、免抽水及 Joker 分組／多解優先序是明示擴充，
不宣稱完整複製該賭場的有限 Joker 規則。特別是五條搭配任意額外對子都保留五條。

## 持久化與結算

沿用既有 cards JSONB、deadline、帳戶鎖、operation_id、版本與流水，不新增 schema。
cards 保存原牌、剩餘牌組、規則版本、玩家選擇、玩家固定建議及莊家最終分墩。
舊版水晶賭場仍須先依既有文件 migrate；已支援 21 點的 schema 不需新遷移。
initialize 可重跑並保留舊遊戲、在途牌九與選牌期限。

每人跨遊戲只能有一局 active。開局扣款與保存發牌同交易；結算、返還及流水同交易。
牌九沒有額外扣款，基本下注、倍率與大額精確整數沿用既有規則。
連點／重送／失效版本／手動確認與逾時競態均不能重複扣款或派彩。
COMMIT 結果未知時先按牌局與版本查證，不盲目重做。

開局起固定 120 秒；選牌、自動分牌、恢復面板都不刷新期限。
到期會使用開局時保存的 House Way 建議，自動確認並結算，覆蓋尚未確認的手動預覽。
選牌期限結束後不能藉由舊面板繼續改選。
重新 /賭場 或重啟恢復原局；有效版本的規則可持續使用，未支援版本視為不可恢復狀態。
後續若新增規則版本，需要保留舊版本驗證與結算能力，不能直接改寫 v1。
