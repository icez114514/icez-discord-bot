# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for
`icez114514/icez-discord-bot`. Use the `gh` CLI.

## Conventions

- Create: `gh issue create`
- Read: `gh issue view <number> --comments`
- List: `gh issue list`
- Comment: `gh issue comment`
- Label: `gh issue edit`
- Close: `gh issue close`
- Publishing to the tracker means creating a GitHub issue.
- PRs are not used as a triage request surface.

Wayfinder maps use `wayfinder:map`; child tickets use
`wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`,
or `wayfinder:task`. Prefer native GitHub sub-issues and dependencies.
