# Domain Docs

This repository uses a single-context layout.

Before exploring, read `CONTEXT.md` and relevant ADRs under
`docs/adr/` when they exist. Missing files should not block work.

Use terminology defined in `CONTEXT.md`. Explicitly flag proposals
that contradict an existing ADR.

Expected layout:

```text
/
|-- CONTEXT.md
`-- docs/adr/
```
