## 個人設定

- 登入後的「個人設定」提供三個具名選項（牌桌選項不再重複提供音效設定），依御姊、少女、貓娘排序，清楚標示目前選取項目。
- 預設御姊；舊偏好缺少語音組、或儲存的 ID 不合法時，也回退御姊。
- 點選任一組立即保存並播放該組 All-in；再次點選同一組可重播試聽。僅開啟設定或還原偏好不自動播放。
- 選擇影響此使用者聽到的所有牌局動作語音，不改變其他玩家偏好，不送出牌局指令。
- 沿用音效偏好的同裝置、分帳號 localStorage 保存；儲存失敗仍保留本次會話偏好並顯示提示。跨裝置同步不在本次範圍。
- 試聽遵循總靜音、總音量、動作語音音量與背景分頁限制。選擇本身不解除靜音。
- 快速切換需停止前一組聲音，過期載入不得回頭播放。切帳號、調音量或靜音同樣取消待播的舊聲音。
- 手動選擇試聽允許最多 10 秒載入；牌局即時音效仍維持 600 ms 過期限制。

## 驗收

1. 三個選項的名稱、順序及 All-in 試聽符合定檔組別。
2. 選擇後的六種牌局語音均來自該組；3-bet／4-bet 仍使用該組 Bet。
3. 切換帳號與重新載入維持各自偏好；未知 ID 和舊格式安全回退。
4. 快速切換、首次音效解鎖、慢載入、靜音及音量為零不誤播。
5. 正式音檔 SHA-256 與定檔索引一致；第 2 組 Bet 為 0.8 秒，四個最新短句皆為 0.9 秒。
