# 德州撲克：個人化下注、易讀牌面與安全重連操作

已發布：https://github.com/icez114514/icez-discord-bot/issues/32

已核准的工作票；涵蓋範圍與驗收條件如下。
覆蓋規格項目：3、7、10、11、12。

## What to build

玩家可點自己的桌上籌碼切換 BB／實際額，設定翻牌前 BB 與翻牌後底池比例按鈕，選四色牌與大字模式，並安全預選下一次過牌／固定額跟注。斷線與恢復時，介面清楚說明同步、控制權和未確認操作，避免誤操作。

沿用既有指令、單一控制端與重送機制；此票完整處理桌規資料、偏好、操作 UI 與驗收。必要的操作狀態整理先在本票內完成，不拆純重構票。

## Acceptance criteria

- [ ] 點自己桌上籌碼可切換實際整數與 BB；換算來自可靠大盲資料，精確計算不損失大額整數，無效大盲回退實際額。
- [ ] 首版只切自己的桌上籌碼；BB 建議最多兩位小數、去尾零，四捨五入時標約值並可查看原額；切換不送帳務指令。
- [ ] 可設定翻牌前 BB 倍數與翻牌後底池比例按鈕；僅填草稿，按下注才送出，保留 raise-to、跟注後底池與伺服器合法上下限語意。
- [ ] 非整數 BB 倍數以明確的整數籌碼取整規則顯示實際提交額；短碼、未重開加注權或全下時不繞過合法性與確認。
- [ ] 四色牌、大字模式可選，保留原本預設牌色與三主題，花色符號仍可辨識；偏好保存且失敗不影響行動。
- [ ] 提供可取消的「可過牌就過牌，否則取消」與「跟注目前顯示金額」，預設未啟用；只適用本手本街下一次本人行動。
- [ ] 預選在輪到本人時重驗金額、合法動作、期限與控制權；其他玩家正常行動造成 turn 遞增不直接失效。
- [ ] 跟注額變更、換街、新手、離桌／坐出、斷線、控制權轉移或本人已行動即清除；預選跟注若是全下，取消自動執行並回一般面板確認，不支援跟注任何額、預選加注或預選全下。
- [ ] 可見狀態區區分恢復連線、同步桌況、已同步；連線成功不等同同步成功，也不等同未確認指令已成功。
- [ ] 另呈現結果待確認或另一視窗控制；保留原 command_id 與原內容的重送方式，不用新意圖重做同一次扣碼。
- [ ] 未同步、無控制權或結果仍未明時鎖住相應操作並說明原因；恢復後顯示目前行動者和正確期限，清掉過期預選。
- [ ] 登入撤銷、關桌、離桌、凍結有正確提示，不無限宣稱恢復中；輔助科技可讀取，斷線抖動不刷屏，不改既有逾時規則。
- [ ] 整合與瀏覽器驗收涵蓋極大額、未知 BB、合法界限、固定額預選、正常輪轉、跨街／視窗失效、回覆遺失及重送；320／390px、桌機、三主題與放大文字可操作。

## Proposed defaults

BB／下注按鈕／牌面偏好先以同裝置分帳號保存，沿用五個快捷按鈕位置；跨裝置同步不列為首版承諾。既有全下確認保持有效。一般鍵盤可及性必須保留，但不新增自訂快捷鍵功能。

## Blocked by

None (can start immediately)。沿用現有桌況與指令契約，不要求先完成籌碼動畫。連線提示所需音效沿用當時可用播放器；完整音效與分組設定由視聽回饋票交付，不因共用元件而新增阻擋依賴。

## Scope boundaries

不新增斷線寬限，不改帳務、判勝、盲注、補時或 NPC；不做補碼捷徑、自動補碼、私人筆記、額外鍵盤快捷鍵與大廳篩選。不包含部署。
