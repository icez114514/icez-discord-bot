## What to build

玩家能查看自己參與的上一手摘要與完整已結束手牌，按步驟前後、播放／暫停、跳街並查看最終結算；即使當時斷線，也能查看伺服器保存且有權查看的歷史。摘要與回放合成一張完整票，不只交付入口或資料 API。

沿用先完成的公開動作與結算語意，完成歷史資料、權限、讀取與回放 UI。若既有歷史無法提供完整事件，必須明示資料不完整與支援起點，不得從最終快照捏造操作。

## Acceptance criteria

- [ ] 上一手摘要可看到各街公開操作、牌面、主池／邊池得主、實領與退款；數字與權威結算相符。
- [ ] 回放具前後一步、播放／暫停、跳街及最終結算；順序由伺服器持久化歷史決定，不受本次連線 80 筆紀錄限制。
- [ ] 每次歷史讀取皆驗證登入者確實參與該手，非參與者不得取得資料；離桌不抹掉已參與手牌的合法查看權。
- [ ] 僅提供自己的底牌及合法公開牌；未公開棄牌底牌不因牌局結束洩漏，回放在揭牌前不預先展示之後才公開的他人牌。
- [ ] 回放與即時桌況隔離，回放按鈕不送牌局操作、不入帳、不觸發即時 WIN／收款音；輪到自己提供返回即時牌桌的提示且不暫停期限。
- [ ] 支援斷線期間已持久化歷史；缺資料或舊格式明確提示，不偽造缺失行動。
- [ ] 明確記錄可回放歷史的起點、查詢分頁與保存政策；不為新增回放任意刪除既有帳務／稽核紀錄，不增加公開分享或匯出。
- [ ] 以歷史存取及瀏覽器驗收覆蓋非參與者拒絕、離桌後查看、斷線、分池／退款、未公開牌保密、跳街、播放暫停及返回即時桌況。

## Proposed defaults

首版查詢採有限筆數分頁，保留既有資料保存政策，不新增自動刪除；若需要新保存期限，於開始實作前明確定案。只回放可驗證的完整歷史，不承諾補齊原本沒有記錄的舊手牌。

## Scope boundaries

不改遊戲、帳務或補時規則；不提供他人私有底牌、公開旁觀、公開分享、私人筆記與新分析統計。不包含部署。
