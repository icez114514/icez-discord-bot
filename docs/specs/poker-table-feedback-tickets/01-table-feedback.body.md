覆蓋規格項目：1、2、4、5、6、8。

## What to build

讓玩家從下注、跨街收池到主池／邊池分配，都能透過籌碼移動、行動標籤、頭像 WIN 與音效看懂牌局；可展開結算明細並設定各類音量。涵蓋所需公開資料、呈現與驗收，不另開純基礎設施票。

先在本票內整理最小共用事件處理，再完成玩家可見功能。公開事件需有穩定識別、動作與金額語意；結算需區分各池實領與退款，不輸出私有整份快照。這份資料同時供後續手牌回放重用。

## Acceptance criteria

- [ ] 盲注、跟注、下注、加注、全下以本次新增投入移動；跨街收池不讓已包含投注的總底池重複增加。
- [ ] 主池、邊池、平分與奇數籌碼依伺服器結果分配；明細顯示各池金額、得主、實領及獨立退款，加總吻合結算。
- [ ] 真正贏得底池者收款時顯示 WIN 及派彩數字；僅收到未跟注退款或作廢退款者沒有勝利效果，不把派彩當成整手淨獲利。
- [ ] 同一人領多池可多次收到籌碼，但主慶祝每手每人只一次；新手、換桌與座位更換不殘留標記。
- [ ] 已確認過牌、棄牌、跟注、下注、加注、全下有短暫行動標籤；金額分清本次投入與加注至，不遮住必要的連線／坐出狀態。
- [ ] 發牌、公共牌、投入、過牌、棄牌、收池、派彩、退款、輪到自己、倒數、補時、操作結果與補碼完成等適用事件具音效覆蓋；同次翻牌與結算不互相漏播。
- [ ] 分類音量、總音量、總靜音與試聽可用並保存偏好；試聽不越過靜音，不送遊戲指令，音效失敗不阻塞牌局。
- [ ] 同意圖的 HTTP 回覆、WS 推播、重繪不重播；初始載入、背景恢復、重連不追播舊動畫或音效，未知中間事件不猜測。
- [ ] 常用音效載入、併發與優先序能保護回合提示，但尊重使用者關閉設定；保留瀏覽器互動解鎖並可診斷不發聲原因。
- [ ] 動畫不負責入帳、不拖延伺服器期限；提供減少動態效果，手機／桌機及三主題不遮住牌面與行動按鈕。
- [ ] 以公開事件／結算資料的整合測試及實際瀏覽器驗收覆蓋多人收池、多邊池、退款、重複訊息、同次翻牌結算、靜音、慢載入與減少動態效果。

## Proposed defaults

動畫每段約 200–450 ms，WIN 約 1–1.5 秒且最遲下一手清除；可在驗收時調整。分組建議為回合提醒、牌局籌碼、結算勝利、介面提示。偏好先以同裝置分帳號保存，儲存失敗仍維持本次會話。

## Blocked by

None (can start immediately)。重連時去重與不追播屬本票基本行為，不等待另一票的新狀態提示 UI。

## Scope boundaries

不改帳務、判勝、盲注、補時或 NPC；不新增被排除的補碼捷徑、自動補碼、私人筆記、額外鍵盤快捷鍵、大廳篩選。此票不包含部署。
