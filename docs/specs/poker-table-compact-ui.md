# 牌桌介面精簡與預選操作（已核准）

日期：2026-09-16。本規格取代舊牌桌回饋草稿第 11 節的固定金額跟注規則；僅修改呈現與前端預選，不更動伺服器牌局及帳務規則。

## 固定版面與資訊

- 移除桌面 ICEZ POKER 字樣、等待下一手與常態在座文字。桌名、盲注、玩法及連線資訊改由圖示提示提供。
- 底池標籤與金額上下排列，整塊水平置中，保留固定高度容納長金額，不能因文字換行推動公共牌或座位。
- 牌局功能入口使用 SVG 圖示；大廳及彈窗保留文字。姓名、籌碼、下注金額、正式動作按鈕及動作標籤仍顯示文字。
- 狀態圖示取代離線、坐出、排隊離桌等常駐文字；重要錯誤、確認及輔助科技通知保留。
- 圖示具可讀名稱及至少 44px 操作區。滑鼠懸停、鍵盤聚焦顯示提示；手機長按 500ms 顯示提示並抑制該次點擊，移動超過 10px 取消長按，單點正常操作。
- 本人回合才顯示正式下注面板；非本人回合隱藏且 inert，保留固定空間，不改變牌桌大小。等待、結算及回合切換的牌桌／公共牌／座位座標保持一致。

## 預選

- 等待本人回合時只提供「棄牌／過牌」與「跟任何注」兩個文字按鈕，互斥，再次點選取消。
- 棄牌／過牌：輪到自己可過牌則過牌，否則棄牌。
- 跟任何注：依最新伺服器合法金額跟注，無需跟注則過牌；跟注會投入全部剩餘籌碼時開啟既有全下確認，確認前不送出指令。
- 前端 Preselection.action 使用 `check_fold`／`call_any`，不再固定跟注額；一般加注不取消預選。
- 只對本手本街下一次本人行動有效；換街、換手、斷線、失去控制權、本人已行動、坐出、離桌、事件遺漏或牌桌不可操作時取消。
- 消費預選時先清除，再使用最新版本與回合構造既有 act 指令；重複快照不可重送。保留現有 command_id 重試、伺服器期限與合法性檢查。

## 個人設定與離桌

- 音效、語音組、減少動態效果只保留於個人設定；牌桌選項不再重複提供音效設定。牌桌保留靜音捷徑。
- 只有自己的頭像可開啟座位選單；他人的頭像不提供離桌。
- 離桌入口由牌桌選項移至頭像選單，沿用 leave 指令。有進行中手牌時標示「本手結束後離桌」，不直接棄牌；已排隊不可重複申請。
- 選單支援 Escape、外部點擊及關閉按鈕，關閉後恢復原觸發焦點。返回大廳仍保留座位。

## 驗證

- 單元測試覆蓋連續加注、免費過牌、自動棄牌、全下確認，以及換街／控制權／連線失效取消。
- `poker_web/tools/check_table_ui.cjs` 使用隔離 API 與 WebSocket fixture，在 Windows Chrome 驗證 320／390px／桌機、三主題及放大文字，檢查穩定座標、底池置中、單次送出、設定去重、頭像選單及提示互動。
- 執行 TypeScript 檢查、完整前端測試及 Vite 建置。瀏覽器測試不使用真實 Discord 帳戶或資產。

## 實際操作驗證後的調整（2026-09-16）

- 牌桌上方整合為單排六個主要入口：返回、桌況資訊（含連線狀態）、回放、靜音、牌桌選項、個人設定。統計／管理移至個人設定內；牌局紀錄由本手牌局視窗進入，減少重複入口。
- 等待預選與正式下注共用同一個固定操作區；不將預選放在隱藏下注面板之後，手機不需跨過空白尋找按鈕。預選增加圓點顯示目前選取狀態。
- 試聽統一經 sound.preview 等待瀏覽器解鎖，容許 10 秒載入；每次試聽取代前一次，避免舊試聽佔滿牌局的併發上限。牌局提示仍從原請求時刻起算 600ms，避免解鎖後補播過期事件。
- 語音定檔素材、音量偏好與靜音規則保持不變；新的瀏覽器音訊檢查使用正常自動播放政策、真實滑鼠點擊及真實靜態音檔，驗證各組試聽及牌局事件產生非靜音 AudioBuffer。

## 房主空位操作與本手位置（2026-09-16）

- 空位只顯示醒目的 1–6 號數字，不顯示「空位」；房主可點選並經第二次確認加入 Bot，其他玩家只看到數字。
- `add_npc` 新增可選整數 `seat`（0–5），省略時沿用第一個空位；省略欄位不加入舊指令的 fingerprint，維持既有重送相容性。seat 只允許出現在 add_npc。
- 後端確認房主、控制權、版本、維護狀態及座位仍空；已占位回傳 seat_occupied，錯誤不發放 NPC 籌碼。確認期間座位被占用時，前端禁止確認。
- Bot 沿用現有 10,000 籌碼與手間加入流程；不插入進行中的手牌。
- 位置由本手 players 原始順序及 button 索引推算，不按目前未棄牌人數重算，不把下手才加入的人算入。
- 由 BTN 開始順時針：6 人 BTN／SB／BB／UTG／HJ／CO；5 人 BTN／SB／BB／HJ／CO；4 人 BTN／SB／BB／CO；3 人 BTN／SB／BB；2 人 BTN / SB／BB。
- 每名本手玩家頭像上方顯示位置標籤，莊位另有桌面 BTN 圓形按鈕標記；換手跟隨新的莊位，尚無手牌時不猜測位置。
- 命名參考：[PokerStars 位置說明](https://www.pokerstars.com/poker/learn/news/hijack-cutoff-and-under-the-gun-pokers-seating-positions-explained-pokerstars-blog/)，雙人盲注依本專案 rules.create 的既有規則。

## 桌機短視窗排版（2026-09-17）

- 桌機牌桌採獨立固定操作列，公共牌與本人座位不得互相覆蓋。
- 桌機容器最寬 1480px，牌桌區至少 600px 高（放大牌面為 620px），最高 720px；視窗較矮時頁面垂直捲動，不壓縮牌桌。
- 等待開局、本人回合、他人回合及結算沿用相同尺寸；回歸檢查包含 1100×500、1200×540、1366×768、1920×1080、2560×1440。
- 結算摘要放在公共牌下方的固定資訊區，不隨整頁高度偏移或覆蓋下注區；一般與放大牌面皆驗證矮視窗捲動可達操作按鈕。

## 視窗內操作與籌碼外觀（2026-09-17，取代上一節桌機捲動配置）

- 桌機操作區獨立於牌桌右側，全部下注按鈕須在初始視窗內；牌桌以 1100×620 的畫布依可用空間等比例縮放，不改變座位或公共牌彼此的比例。小螢幕操作區固定在視窗底部，頁面保留底部空間供座位捲入可見區。
- 等待與本人回合仍使用同一操作區；不可預選且非本人回合時隱藏面板外框。
- 棄牌用暗紅、過牌／跟注用綠、加注用金、全下用亮紅；保留文字、停用和鍵盤焦點提示。
- 本人下注籌碼在座位右上，BTN 在座位右側，兩者不得重疊。下注與飛行籌碼共用有邊紋、厚度、陰影的 SVG 堆疊圖案；圖案為裝飾，實際金額以旁邊文字為準。
- 縮放後的籌碼動畫將視窗座標換算回牌桌座標。桌機 5 種視窗、一般／放大牌面皆驗證不需捲動即看見操作按鈕及本人座位。
